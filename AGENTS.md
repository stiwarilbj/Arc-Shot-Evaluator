# Repository instructions

## Keep the README current

For every future change, review `README.md` and update affected feature
explanations, navigation/names, setup commands, build targets, storage behavior,
requirements, and limitations in the same task. Do not ship a feature addition,
removal, or rename with an outdated README.

Describe the current implementation. Distinguish hosted and downloaded behavior,
and keep unavailable collections and unverified capabilities clearly identified;
do not present plans, targets, or passing builds as completed features. Keep the
README focused on how to use the app, linking detailed technical guides where
appropriate.
